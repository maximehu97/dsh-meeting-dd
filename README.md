# dsh-meeting-DD：钉钉版多智能体协商插件

> 一条命令安装：`curl -fsSL https://raw.githubusercontent.com/maximehu97/dsh-meeting-dd/main/install.sh | bash`

**每个人一个 AI 助理，助理之间在钉钉里谈：约会议、协调排时间、团建投票点奶茶。**

这是一个 DeepSeek Harness（dsh）插件，是局域网版 dsh-meeting 的钉钉版。功能和页面跟局域网版一样，区别只在通信：

| | dsh-meeting（局域网版） | dsh-meeting-DD（钉钉版） |
|---|---|---|
| 助理之间的协商报文 | A2A，直接连到对方电脑的端口 | 钉钉单聊，以本人钉钉身份发出（带 AI 标识） |
| 收信 | 本机 A2A 端口对局域网开放 | 钉钉事件长连接（DWS），不开放任何端口 |
| 找同事 | mDNS 自动发现 / IP / 邀请码 | 按姓名在钉钉通讯录里搜 |
| 人和人的消息 | 节点之间直接转发 | 钉钉单聊，对方在钉钉里直接能看到、直接回 |
| 要求 | 同一个局域网 | 同一个钉钉组织，各自登录钉钉 |
| 默认端口 | 4500 / 41500（对局域网） | 4600（只对本机），本机助理在 dsh 进程内直接调用 |

两个插件可以装在同一个 DSH 里，端口、数据目录（`~/.dsh-meeting` 和 `~/.dsh-meeting-dd`）、侧栏按钮都分开。

## 怎么工作

- 每个人在自己电脑上的 DSH 里装这个插件。侧栏多一个「约会议·钉钉」按钮，点进去是横版平板样式的助理页：💬 助理、💭 消息、📅 日程、🧠 记住的、👥 同事，右侧是钉钉协商报文和同事列表。
- 对助理说「约刘经理、赵经理开个双十一联合方案会，周四，一小时，越早越好」，助理会通过钉钉给对方的助理发 SYN（问空闲）→ 收 SYN-ACK → 求交 → 必要时 RELAX（请对方本人松绑）→ PROPOSE → ACK → 订会议室 → CONFIRM，各方日程同时写入。
- 每条报文是一条普通的钉钉文本消息：上面是人能读懂的一句话（比如「🤖 李经理的助理 · 问空闲：想约你周四开一小时会」），最后一行是机器读的 `⟦DSHM·1⟧{json}`。太长的报文会自动拆成几条。
- 对方助理收到后在对方电脑上处理，需要本人拍板（比如占用午休）时在对方的页面弹卡片，由对方本人点。
- 隐私规则不变：对外只给「可用 / 勉强 / 需本人点头」三类时段，不给原因；奶茶投票只给分数和饮品，不说忌口原因。
- 对方还没装插件时，助理会用普通钉钉消息联系对方本人说明来意；对方在钉钉里直接回复的文字会显示在「💭 消息」里，但不会触发自动协商。

## 部署（每个人在自己电脑上做一次）

需要：Mac / Linux，Node.js 20.19 / 22.12 或更新，已经在用 DeepSeek Harness（dsh）网页版，和一个加入了公司钉钉组织（比如「九派科技」）的钉钉账号。不需要钉钉开放平台应用，也不需要填任何密钥。

### 1. 安装（一条命令）

```bash
curl -fsSL https://raw.githubusercontent.com/maximehu97/dsh-meeting-dd/main/install.sh | bash
```

它会从 GitHub 最新发布版下载安装包，装进 DSH 网页版（profile `web`），并顺带装好钉钉 CLI（`npm install -g dingtalk-workspace-cli`）以及缺的 pnpm、dsh。装完重启 DSH 网页版，侧栏多出「约会议·钉钉」。

也可以到 [Releases](https://github.com/maximehu97/dsh-meeting-dd/releases) 下载 `dsh-meeting-dd-kit-<版本>.zip`，解压后运行里面的 `./install.sh`。想单独建一个 profile：`DSH_PROFILE=meeting-dd ./install.sh`，之后用 `./start.sh` 启动，页面在 http://127.0.0.1:4600/ 。

### 2. 扫码登录钉钉

打开「约会议·钉钉」，页面会直接请你登录钉钉。点「登录钉钉（扫码）」，浏览器打开钉钉授权页：用手机钉钉扫码，选公司（九派科技），点「同意」。

第一次用时，钉钉可能提示「暂无 CLI 数据访问权限」：选审批人（公司管理员）提交申请，管理员在钉钉里批准后自动完成登录。也可以在终端运行安装包里的 `./login.sh`。

### 3. 登录后自动完成的事

- **身份**：直接用你的钉钉姓名、部门、职位和主管，不用选身份。可以在「🧠 记住的」里改。
- **示例档案**：按你的钉钉账号自动生成一套示例日程（未来一周）、偏好和手机里的原始记录（周末安排、奶茶口味、体检备注等），每人不同。可以在「📅 日程」「🧠 记住的」里改成自己的真实安排，或重新生成一套。
- **自动发现同事**：给本组织每位同事发一次打招呼。装了插件的同事会自动回应，出现在「👥 同事」里；没装的只会收到一条可以忽略的说明。新同事入职后可以点「重新发现」。

### 4. 开始用

在「💬 助理」里对助理说话：

- 「约 张三 明天下午开半小时会」「这周末约大家出去玩半天，顺便团一波奶茶」
- 「@张三 @李四 周四下午开个一小时的方案会」：@ 到的人就是协商对象，你的助理会去找他们的助理谈，谈好了再告诉你。
- 想直接给某人发一句话（不经过助理），在「💭 消息」里发，对方在钉钉里能看到。

### 注意

- 不要和别的钉钉自动回复插件（比如 dsh-dingtalk）装在同一个 DSH 里，两个插件会同时处理同一条钉钉消息。
- 电脑要开着、DSH 要在运行，助理才能收发。电脑睡眠期间对方发来的报文不会补处理，对方助理等到超时会告诉对方本人。
- 用公司自建的钉钉应用登录（可选）：「👥 同事」→「高级：用自己的钉钉应用」，或安装时传 `DINGTALK_CLIENT_ID` / `DINGTALK_CLIENT_SECRET`，凭据只存本机 `~/.dsh-meeting-dd/dingtalk.json`（权限 600）。

## 配置项

在 profile 的 `cordis.patch.yml` 里改 `meeting-dd` 条目（dsh 的 patch 会整份替换 config，改端口时用 `node lib/patch.mjs --port 4601` 生成完整叠加层）：

| 配置 | 默认 | 说明 |
|---|---|---|
| `port` | 4600 | 手机页 / 本机 MCP 端口 |
| `host` | 127.0.0.1 | 只给本机访问 |
| `preset` | meeting-dd | 本机助理用的 agent preset（插件自带） |
| `dataDir` | `~/.dsh-meeting-dd` | 本人数据 |
| `credsFile` | `~/.dsh-meeting-dd/dingtalk.json` | 可选：自建钉钉应用的凭据（本机文件，权限 600） |
| `dwsPath` / `dwsProfile` | `dws` / 空 | 钉钉 CLI 路径；多组织时指定 `corpId:userId` |
| `aiTag` | true | 助理发出的钉钉消息带 AI 标识 |
| `replyTimeoutMin` | 30 | 等对方助理回复的最长分钟数 |
| `loopDir` | 空 | 测试用：填一个目录就改用本机假钉钉信箱，不联系真人 |

## 安全和限制

- 默认用钉钉 CLI 自带的应用登录，插件里没有任何密钥；自建应用的凭据只在本机凭据文件里。手机页只监听 127.0.0.1，写操作只接受本机页面发起的请求。
- 协商报文以本人钉钉身份发出，对方在钉钉聊天里能看到全文（包括 `⟦DSHM⟧` 机器行）。助理的提示词要求只给忙闲不给原因。
- 只处理带 `⟦DSHM⟧` 标记的来信和已添加同事的普通回复，不读取、不导入其他钉钉聊天。
- 钉钉没有在线状态：「助理已接入」表示对方插件回应过。对方 dsh 没开时，报文会留在钉钉聊天里，但对方助理不会补处理，发起方等到超时后告诉本人。
- 发送失败（网络、权限）会进发件箱，每分钟重试；「已提交」不等于对方已读。

## 本机联调（不联系真人）

```bash
npm test   # 协议单元测试：两个节点通过假信箱打招呼、私聊、协商、分片
DSH_MEETING_DD_LOOP=/tmp/ddloop DSH_MEETING_DD_LOOP_NAME=李经理 DSH_MEETING_DD_PORT=4611 ./kit/start.sh
DSH_MEETING_DD_LOOP=/tmp/ddloop DSH_MEETING_DD_LOOP_NAME=刘经理 DSH_MEETING_DD_PORT=4612 ./kit/start.sh
```

同一个信箱目录里的节点互相能搜到、能协商，模型照常用各自 dsh 的配置。

## 只有一个钉钉账号时：单账号模拟

钉钉不会给「自己发给自己」的消息推送事件，但「我自己」会话里的消息可以读出来。设置 `simDir` 后，本机几个节点共用同一个钉钉账号：报文发到「我自己」会话，第一行带路由头 `⟦DSHS 收件节点 发件节点⟧`，各节点每 2.5 秒读一次，只处理发给自己的。报文真实经过钉钉，本人在钉钉里能看到全过程。

```bash
DSH_MEETING_DD_SIM=~/.dsh-meeting-dd-sim DSH_MEETING_DD_LOOP_NAME=李经理 DSH_MEETING_DD_PORT=4611 ./kit/start.sh
DSH_MEETING_DD_SIM=~/.dsh-meeting-dd-sim DSH_MEETING_DD_LOOP_NAME=刘经理 DSH_MEETING_DD_PORT=4612 ./kit/start.sh
```

四个原始场景用 8 个助理通过钉钉跑通的回放见项目 Releases 附件。
